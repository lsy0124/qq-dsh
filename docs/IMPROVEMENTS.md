# 本次完善：0.3.0

## 可重现的修复

- **启动器可移植**：当前 Node 执行、配置校验、Desktop 凭据目录默认值、保留显式环境设置、前台启动与后台日志分开，进程创建不冒充服务健康。
- **配置与路径**：提取 runtime-config，处理 BOM、空文件、坏 JSON、错误端口／URL／ID；不覆盖坏文件，不打印凭据；路径支持环境、配置和 PATH 命令。ASR 修正 Windows URL 路径解码问题。
- **媒体进程**：提取 media-process，避免 UTF-8 分块乱码，输出上限、超时、取消、缺少程序的诊断；只清理自己启动的任务，Windows taskkill 失败时补直接子进程终止。
- **素材筛选**：提取 song-selection，修复“无伴奏”被“伴奏”子串误判、吉他伴奏误分类、非法／负／非有限时长、非法播放量造成 NaN 排序。
- **可选依赖**：RVC 缺少时先明确报错，不先触发 GPU/ComfyUI 操作；抖音验证码适配器改成工具调用时懒加载，避免缺少外部工程导致 MCP 启动就崩溃。RVC / ASR / 抖音外部工程仍需使用者提供。
- **安装器**：使用保留注释／标签的 YAML AST 删除受管条目，修复共享 insert、引号 ID、flow YAML、旧根 `[]`、重复运行；坏 YAML 保持不动。模板用 `qq-dsh:` 标记，安装到 DSH 私有副本时替换实际路径，公开源码不落地本机路径。
- **协议兼容防护**：删除源预设里已被新版宿主移除的 `{{cwd}}` 提示词变量；不据此声称所有 DSH 版本均兼容。
- **默认行为与权限**：空白名单、关闭主动发送与语音；保留工具限制和会话令牌。抖音实际评论／私信默认关闭，需在适配进程显式打开。
- **发布检查**：高置信凭据检查先于历史的整文件误报豁免；修正正则未启用 global 导致重复匹配和提前截断；不回显命中原文。
- **Windows 工具**：启动批处理用 ASCII / CRLF；重启仅核验当前仓库绝对入口及锁文件 PID，避免结束其他项目。

## 整理与测试

官方 npm 审计发现并修复了 8 项依赖告警；采用范围内的兼容更新，锁定 YAML 2.9.1、MCP SDK 1.32.2、Zod 4.6.7 等版本，随后完成缓存清洁重装及离线回归。

新建 `npm run init`、`doctor`、`test:core` 和统一 `npm test`；原有离线审计仍保留。安装测试补上新增解析器依赖、ASCII 的模拟 .cmd 夹具，避免中文路径被本地代码页损坏。实际宿主工具名对账改为显式提供目标包目录，纯离线测试不自动选择旧版全局 CLI。

上游缺失的控制台页面按同版本补齐。原有文档归档，新 README 区分普通桥接与外部扩展。排除日志、缓存、调试备份、账号数据和原始压缩包；不移植私人音色与运行资料。

没有整体重写 bridge.js；本次只抽离配置、路径、媒体进程和素材评分这几个可测边界，其他会话／唤醒逻辑保留。完整真实运行仍需安装自己的网关和 DSH 后验收。
