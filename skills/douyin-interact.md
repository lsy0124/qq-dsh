# 抖音互动

你有一个真实的抖音账号，能看、能读、能回。**不是查资料，是真的在操作。**

## 先搞清楚页面结构

抖音有两种页面，评论区位置完全不同：

| URL | 是谁的作品 | 评论区 |
|---|---|---|
| `/video/<id>` | 别人的 | 页面下方，**默认展开** |
| `/note/<id>` | 图文作品 | 右侧面板，要点「评论(N)」tab |
| `/user/self?modal_id=<id>` | 自己的 | 弹窗模式，右侧图标栏，**默认收起** |

**遇到读不到评论，先想是不是页面类型不对。**

## 读评论：`douyin_comment_list(aweme_id)`

返回每条的**昵称 / 内容 / 时间 / 地区 / 是否作者**。

```
1. [Tuk] 好搞笑，准备蔬菜的时候就看不见狗影了（1周前·重庆）
2. [喂猪被哄飞.] 主播，有狗偷吃 [作者回复过]（1周前·湖北）
3. [莳羽] 咱这孩子吃的还能再不体面一点不 [作者回复过]（1周前·山东）
```

**会自动滚动加载更多。** 想要更多评论就调大 `limit`。

## 回复评论：`douyin_reply(aweme_id, reply_text, match_text?)`

**优先用 `match_text` 精确匹配，不要用 `index` 盲选。**

```
✅ douyin_reply(
     aweme_id: "...",
     match_text: "有狗偷吃",        ← 那条评论里包含的文字
     reply_text: "它已经吃完了，还打包了一份"
   )

❌ douyin_reply(aweme_id: "...", index: 3, reply_text: "...")
   （第几条会变，不稳定）
```

**`match_text` 取那条评论里**最有辨识度的片段**，6-10 个字够，别取开头（很多人开头一样）。

## 发新评论：`douyin_comment(aweme_id, text, at?)`

和 `douyin_reply` 的区别：

- `douyin_comment` = 发**新的顶层评论**
- `douyin_reply` = 回复**别人的某条评论**（对方会收到通知）

## 查 @ 提醒：`douyin_notifications(limit?, only_interaction?)`

**这是唯一能看到「有人在评论区 @ 你」的地方。**

抖音没有推送接口，它是**被动查询**。

**什么时候该查：**

- 对方说「我在抖音 @ 你了」「评论你了」「看到我留言没」
- 你自己想看看有没有人找你

**查到就自然回应，别念清单。**

## 读私信：`douyin_read_im(to)`

打开会话，读出所有消息，**并且标明每条是谁发的**。

里面的视频会单独列出来，写清楚是「对方分享的」还是「你自己发的」——**这一点很重要**，别把对方发来的视频当成自己找的，也别反过来。

## 别人发来的分享：`douyin_read_share(share_text)`

消息里出现这种文字就是视频分享：

```
4.35 :0pm cmd:/ 07/10 p@d.aN 标题... https://v.douyin.com/xxx/ 复制此链接...
```

**别当乱码忽略**，原样丢给 `douyin_read_share`，它会解析出视频内容。

三种形态都能认：

```
① https://www.douyin.com/video/<id>
② https://v.douyin.com/<短码>/          ← 会跟 302 重定向
③ 一长串带「复制此链接」的口令文本
```

## 听懂视频：`douyin_transcribe(aweme_id)`

**只有这个能知道视频里真正说了什么。** 标题和评论都是别人写的。

30 秒视频约 10-20 秒。想认真讲一条视频就调它。

## 怎么写回复

**像人在评论区说话，不像客服。**

- ✅「哈哈哈这个我也遇到过」
- ✅「你这个角度我没想到」
- ❌「感谢您的评论，我们会继续努力」
- ❌ 每条都回（挑有意思的回）

**不要：**

- 不要每条评论都回（像机器人）
- 不要回「谢谢支持」这种空话
- 不要解释技术细节

## 写操作开关

发评论、回复、发作品默认**全部禁用**。要开需要设环境变量：

```
DOUYIN_ALLOW_WRITES=1
```

没开的时候工具会直接拒绝，并说明怎么开。
